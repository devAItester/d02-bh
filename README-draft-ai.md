# d02-bh

## Старт

1. Создай репозиторий на GitHub
2. Создай `assets/`
3. Найди подходящую иконку на [Tabler Icons](https://tabler.io/icons)
4. Скачай выбранный SVG в `assets/`
5. Запусти `make-logo.sh`
6. Получи из иконки `assets/logo.svg`
7. Открой лого и проверь его в светлой и тёмной теме
8. Только после проверки подключай его к сайту

## Команда

```bash
./make-logo.sh assets/brackets.svg assets/logo.svg
```

## Правило

**Сначала выбери готовую иконку. Потом скриптом сделай из неё лого.**

Не проси AI рисовать то, что уже можно получить из выбранного ресурса.
