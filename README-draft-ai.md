# d02-bh

## Старт

1. Создай репозиторий на GitHub
2. Открой репозиторий
3. Создай `assets/`
4. Найди подходящую иконку на [Tabler Icons](https://tabler.io/icons)
5. Скачай SVG в `assets/`
6. Дай файлу понятное имя: `logo.svg`
7. Проверь SVG отдельно на странице
8. Только после проверки подключай его к сайту

## Правило

**Сначала ресурс → потом проверка → потом подключение.**

Не тащи в проект библиотеку иконок целиком, если нужна одна иконка.
