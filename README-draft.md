# d02-bh

## Сделать

1. Создать репозиторий с README.
2. Создать папку `assets` — для исходных ресурсов проекта.
3. Взять подходящую иконку для лого из [Tabler Icons](https://tabler.io/icons).
4. Скачать выбранную иконку в `assets`.
5. Сохранить информацию об источнике и лицензии иконки.
6. Определить, что эта иконка будет использоваться также как фавикон.
7. Создать локальный вспомогательный скрипт `make-logo.sh` — он берёт выбранный SVG и создаёт из него `assets/logo.svg`.
8. Скачать репозиторий на компьютер — начиная с этого шага работа выполняется локально, в терминале.
9. Сделать `make-logo.sh` исполняемым.
10. Запустить `make-logo.sh` из корня локального репозитория.
11. Проверить созданный `assets/logo.svg`.
12. Проверить лого и фавикон в светлой и тёмной теме.
13. Использовать выбранную иконку как фавикон проекта и лого.

### Локальный запуск

`make-logo.sh` — вспомогательный Bash-скрипт для локального выполнения. Он находится в корне репозитория и запускается из корня локальной копии:

```bash
./make-logo.sh assets/brackets.svg assets/logo.svg
```

Скрипт проверяет исходный SVG и создаёт из него `assets/logo.svg`.

Иконка остаётся исходным ресурсом. Лого создаётся из выбранной иконки скриптом.
