# d02-bh

## Сделать

1. Создать репозиторий с README
2. Создать папку `assets` для ресурсов
3. Взять иконку для лого из [Tabler Icons](https://tabler.io/icons)
4. Скачать выбранную иконку в `assets`
5. Запустить скрипт — создать из иконки `assets/logo.svg`
6. Проверить лого в светлой и тёмной теме
7. Описать источник и лицензию
8. Использовать лого в проекте

### Команда

```bash
./make-logo.sh assets/brackets.svg assets/logo.svg
```

Иконка остаётся исходным ресурсом. Лого создаётся из выбранной иконки скриптом.
